What gets logged (backend guarantee)

  • driver.verify / driver.reject (with reason) / deactivate / reactivate
  • inquiry.status (enterprise status changes)
  • payment.adjust (amount deltas in paise + reason + admin)
  • pricing changes (rate + history + audit in one transaction)
  • Phone, password-hash and token are never logged — only ids and changed fields.

There is no dedicated backend table for failed API requests / suspicious activity — this gap is documented, and no new table was created without permission.
